# Coursework

**University programming labs from my Computer Science degree at Umm Al-Qura University: Java desktop applications and C++ fundamentals and graphics.**

## What's inside

### Java (NetBeans / Maven)

- **JavaFX desktop apps.** A student manager with dashboard, student-list and report screens (FXML controllers); a click counter built with lambda event handlers; and multi-scene apps.
- **Programming labs.** Object-oriented Java exercises using collections (`ArrayList`), plus a final lab exam.

### C++ (Visual Studio)

- **Fundamentals labs.** Introductory console programs.
- **Computer graphics lab.** An OpenGL / freeglut scene with bitmap textures.

## Tech stack

Java · JavaFX · Maven · NetBeans · C++ · OpenGL / freeglut · Visual Studio
